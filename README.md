# Distance-Alert-Gas-Leakage-system
The Distance Alert & Gas Leakage System is a safety and monitoring project designed to detect nearby obstacles and gas leakage in real time. The system uses an ultrasonic sensor to measure the distance between the user and surrounding objects. When an object comes within a predefined safety range, the system generates an alert using a buzzer.
